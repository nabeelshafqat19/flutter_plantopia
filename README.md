# 🌱 Plantopia

> A modern Flutter-based plant e-commerce application designed to provide users with a smooth and engaging shopping experience for plants and gardening products.

---

## 📱 About The Project

**Plantopia** is a Flutter-based e-commerce mobile application focused on plants and gardening products.

The application provides a clean and user-friendly interface where users can explore different plant categories, view product details, manage their shopping experience, and interact with products through a modern mobile UI.

The project is built using **Flutter and Dart**, with **GetX** used for application state management and navigation.

## 🚀 Getting Started

Follow the steps below to run Plantopia locally.

### 1. Clone the Repository

```bash
git clone https://github.com/nabeelshafqat19/flutter_plantopia.git
```

### 2. Navigate to the Project

```bash
cd flutter_plantopia
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Check Connected Devices

```bash
flutter devices
```

### 5. Run the Application

```bash
flutter run
```
